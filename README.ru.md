# Драйвер Canon LBP-810 для современной macOS (Apple Silicon / ARM64)

Открытый нативный драйвер CUPS для лазерного принтера **Canon LBP-810** на современной macOS (Sonoma, Sequoia, Tahoe / macOS 14, 15, 27) для компьютеров на базе Apple Silicon (M1/M2/M3/M4).

[🇬🇧 Read in English (README.md)](README.md)

---

## Описание проекта

**Canon LBP-810** — классический GDI-принтер («host-based»), использующий проприетарный протокол Canon **CAPT v1** и алгоритм сжатия растра **SCoA** (Smart Compression Architecture). Поскольку официальный драйвер от производителя для 64-битных систем macOS и процессоров Apple Silicon отсутствует, данный проект предоставляет полноценное открытое решение:

* **Нативный бекенд CUPS:** Прямая интеграция в системную архитектуру печати macOS без виртуальных машин и эмуляции.
* **Apple Silicon (arm64):** Скомпилирован под нативную архитектуру ARM64.
* **Автономный бинарный файл:** Статическая линковка `libusb`, отсутствие сторонних зависимостей во время выполнения.
* **Интеграция с системным интерфейсом macOS:** Принтер доступен в «Системных настройках», окне очереди печати и в диалогах печати любых приложений (Preview, Safari, Pages, Microsoft Word и др.).
* **Скрытие нерабочего Apple USB:** Фильтрация штатного бекенда Apple исключает появление нерабочего дубликата принтера в окне добавления устройств.
* **Служба автовосстановления (LaunchDaemon):** Драйвер переживает системные обновления macOS без необходимости повторной установки.

## Архитектура работы

```
[Приложение: Preview / Office / Safari]
                   │
                   ▼
         [macOS PrintCore]
                   │
                   ▼
       [CUPS Spooler (cupsd)]
                   │
                   ▼
 [cgpdftoraster] (штатный нативный растеризатор Apple)
                   │
                   ▼ (application/vnd.cups-raster, 600 DPI monochrome)
 [captusb] (CUPS Backend в /usr/libexec/cups/backend/captusb)
       │
       ├── Высокоскоростное сжатие строк SCoA (libcapt)
       ├── Формирование пакетов CAPT v1
       ├── Монопольный захват интерфейса USB через libusb
       ├── Мониторинг статуса принтера и сброс ошибок (Clear Misprint)
       └── Передача прогресса в CUPS (PAGE: N, STATE: ...)
                   │
                   ▼ (USB Bulk transfer)
         [Принтер Canon LBP-810]
```

## Способы установки

### Вариант 1: Графический установщик (Рекомендуется)
Дважды кликните по образу **`dist/Canon-LBP810-macOS.dmg`** и запустите установщик **`Canon-LBP810-Driver-macOS.pkg`**.

### Вариант 2: Установка через терминал
Подключите принтер к USB и выполните:
```bash
./setup.sh
```

Установщик автоматически:
1. Установит бекенд в `/usr/libexec/cups/backend/captusb`.
2. Установит описание принтера (`CanonLBP-810.ppd`) в `/Library/Printers/PPDs/Contents/Resources/`.
3. Настроит системный демон (`com.canon.lbp810.heal`), восстанавливающий файлы в случае их очистки при обновлении macOS.
4. Обнаружит подключённый принтер на шине USB и зарегистрирует очередь `Canon_LBP810`.

## Печать документов

После завершения установки принтер **Canon LBP-810** отображается в разделе **«Системные настройки» ▸ «Принтеры и сканеры»** и доступен в стандартном окне печати (`Cmd + P`).

Печать из терминала:
```bash
# Печать файла PDF
lpr -P Canon_LBP810 document.pdf

# Просмотр статуса очереди
lpstat -p Canon_LBP810
```

## Диагностика и проверка состояния

Если принтер не отвечает или требуется проверить аппаратные статусы:

```bash
./diagnose.sh
```

Утилита выводит:
- Обнаружение устройства на шине USB и его серийный номер.
- Наличие и запуск бекенда `captusb`.
- Состояние очереди печати в CUPS.
- Последние записи журнала `/private/var/log/cups/error_log`.

## Удаление драйвера

Для полного удаления очереди, файлов драйвера и службы автовосстановления выполните:

```bash
sudo ./uninstall.sh
```

## Сборка из исходников и тестирование

Необходимые инструменты:
- CMake >= 3.21
- Xcode Command Line Tools (`xcode-select --install`)
- `libusb` и `pkg-config` (через Homebrew: `brew install libusb pkg-config`)

```bash
# Конфигурация и сборка
cmake -B build -DBUILD_TESTS=ON
cmake --build build

# Запуск модульных тестов
ctest --test-dir build --output-on-failure
```
